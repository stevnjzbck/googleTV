Este repositório contém o código-fonte do livro "systemlab".

This repository contains the source code of the "systemlab" book.

## Requisitos / Requirements

Building requires [partials]:

```bash
$ cargo install partials --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ partials build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ partials test
```
